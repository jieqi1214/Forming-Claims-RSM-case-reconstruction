# S–C Reconstruction Record

An optional one-page record for checking how a material systematic-review conclusion (C) relates to its smallest sufficient completed synthesis finding(s) (S). It accompanies Jie Qi's manuscript *Forming Claims in Evidence Synthesis: From Synthesis Findings to Review Conclusions*. Version 0.3, 26 September 2026.

## Files

- `SC_Reconstruction_Record.docx`: editable Word form.
- `SC_Reconstruction_Record.pdf`: printable one-page form.
- `SC_Reconstruction_Record.txt`: plain-text version for copying or accessible editing.
- `README.md`: this guide.

## Use

Start with one material C and its exact review location. Trace it back through the reported synthesis question(s) to the smallest sufficient completed S, retaining relevant qualifications. Ask what, if anything, remains open if S is accepted. Identify where an additional or disputed proposition first entered and which established method is responsible for appraisal. Record the action on C or the boundary that returns scrutiny to synthesis. Use another copy for a consequential alternative S–C pairing or for a claim requiring different support.

This form documents the route to an appraisal. It does not establish certainty, assess risk of bias, validate a causal claim, or replace existing methods. The four manuscript reconstructions are retrospective demonstrations; this form has undergone a case-based desk test but has not been user-tested with independent participants.
